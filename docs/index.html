功能

常规步骤有默认值，需要时再进高级设置。

PE 从哪来

WinPE 写进本机的一块暂存分区，启动项只生效一次。重启进 PE 开始装，装完删掉这块分区，空间还回原处。

装哪个版本

按本机版本在镜像里挑对应的那个。镜像里版本不止一个时，弹出来让你自己选。

第一次开机

OOBE 跳过，账户、时区、计算机名都配好，用户名沿用原来的。进桌面时这些已经弄完了。

装到哪、怎么装

全新安装、保留文件、整盘重建，三种。系统可以装到另一块盘，也能决定要不要格式化引导分区。会删数据的操作都要再确认一次。

驱动和 Defender

第一次开机时把你准备的驱动包装上，zip、exe、目录都行。要不要顺手禁用 Windows Defender，自己勾。

进度和日志

准备阶段有进度，日志一条条写着。PE 里是图形界面，显示当前在哪个阶段、DISM 走到百分之几。失败了日志留在原地。

流程

前三步在当前系统里做，重启之后就不用管了。

准备

下载镜像与 WinPE，写入本机暂存分区，注册一次性启动项。完成后 10 秒自动重启（可取消）。

进入 WinPE

重启自动进入部署环境；未选中的磁盘不受影响。

自动部署

按所选方案分区并格式化、应用系统映像、重建引导，界面实时显示进度。

首次启动

初始设置和账户建好，驱动装上，进桌面。暂存分区这时删掉，空间合并回原来的分区。

获取 Windows 镜像

CTPrep 不附带系统镜像，请从可信渠道获取原版并校验哈希；本地镜像支持 .iso / .wim / .esd。

官方与公共来源

  • 微软官网 — Windows 10 / 11 官方 ISO 下载（链接有时效，拿到后尽快下载）
  • MSDN, 我告诉你（next.itellyou.cn） — 老牌原版镜像索引，ed2k / BT 链接
  • helloWindows（hellowindows.cn） — 只保留每个版本最新累积更新版
  • msdl.gravesoft.dev / Fido / UUP dump — 按需生成微软官方直链或 ISO

下载后请用官方公布的 SHA256 校验。避开任何 Ghost / 一键装机 / 修改版来源。

用「链接清单」管理下载源

把镜像与 WinPE 的下载地址集中在一个 JSON 清单里（任意静态托管即可）。 换链接、换托管，都只改这个文件。 

{
  "images": {
    "Windows 11 24H2": {
      "url": "https://你的存储/win11_24h2.iso",
      "sha256": "…"
    },
    "Default": { "url": "https://你的存储/win_x64.iso" }
  },
  "pe": { "url": "https://你的存储/CTPrep_PE.wim" }
}

在 config.ini 的 [Image] / [PE] 里直接填清单地址（.json）即可启用，格式详见仓库文档。
